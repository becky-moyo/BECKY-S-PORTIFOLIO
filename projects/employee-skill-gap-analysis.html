Employee Skill Gap Analysis

Flask-based workforce analytics prototype for identifying employee skill gaps and recommending targeted training pathways.

GitHub Repository

Problem Statement

Organizations often struggle to see which employee skills are missing, which roles are most affected, and which training interventions should be prioritized. This project proposes a structured analytics platform that compares employee capability data with role requirements and produces practical recommendations.

Data scope

The prototype is designed around employee profiles, role descriptions, competency frameworks, training records, and scraped job-market skill requirements. Core features include current skills, target role skills, proficiency levels, department, experience, and training history.

Methodology

The system cleans and standardizes skill text with NLTK, extracts role requirements from structured and scraped sources, and uses K-Nearest Neighbors to compare employee profiles with target competency patterns. Recommendation rules then map the largest gaps to training suggestions.

Evaluation and status

This project write-up outlines the intended workflow; it does not report evaluation metrics or include a live demo.
