Banking Service Platform

Financial analytics prototype that uses FinBERT-based NLP to evaluate banking service quality from customer feedback.

GitHub Repository

Problem Statement

Banks receive high volumes of feedback through reviews, support messages, and service channels, but manually interpreting sentiment and recurring pain points is slow. This platform demonstrates how NLP can summarize customer experience signals and guide service improvement.

Data scope

The project is structured for financial customer feedback, complaint categories, service channel labels, transaction context, and manual sentiment labels. The dataset design supports sentiment classification, topic grouping, and service trend analysis.

Methodology

Text is cleaned and prepared for transformer-based classification. A fine-tuned FinBERT model scores sentiment in a banking context, while Flask exposes analysis screens for filtering results by branch, service type, topic, and time period.

Evaluation and status

This project write-up outlines the intended workflow; it does not report evaluation metrics or include a live demo.
